# Contributing

Issues and pull requests are welcome.

- Report bugs and feature requests at https://github.com/dpezer/silverstripe-remote-assets/issues
- Open pull requests against the `main` branch
- Code follows PSR-12 — check with `vendor/bin/phpcs`
- Add or update tests in `tests/php/` for behaviour changes
- Use [semantic versioning](https://semver.org/) for releases
